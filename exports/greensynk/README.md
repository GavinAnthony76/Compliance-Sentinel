# GreenSynk mobile brand assets

- `app-icon-1024.png`: 1024 × 1024, RGB PNG, fully opaque, no pre-rounded corners. The store applies its own icon mask.
- `splash-screen-1290x2796.png`: portrait splash composition, solid emerald background. Preview/export for a tall phone; not a universal device-specific launch-screen file.
- `splash-logo-transparent.png`: 1200 × 600 RGBA PNG. Center this on #059669 using contain sizing (approximately 300 logical pixels wide). Prefer this approach for adaptive native splash screens, rather than stretching the full portrait image.
- `theme-colors.png`: palette reference.
- `theme-colors.json`: suggested mobile color values.

The leaf comes from the existing GreenSynk logo, not a redesigned brand mark. The icon omits the wordmark for legibility at small sizes.

Use #047857 for primary buttons with white labels for stronger text contrast. #059669 is the existing logo green and the splash background. These are suggested mobile theme values; the current website theme has not been changed.

Source SVG files are included for future exports. No mobile app configuration or store submission has been changed.
